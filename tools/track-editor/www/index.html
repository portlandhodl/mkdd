          Getting started

          1. 1

            Open a course ARC (for example Course/Luigi.arc). Models, textures, sky, and collision load automatically.

          2. 2

            Add MRAM.arc once under Files → Model Libraries to see item boxes and shared objects.

          3. 3

            Hold right mouse + WASD to fly, click to select, and drag the gizmo to move things.

          No game data is bundled. Use files you legally own. Files never leave this browser.
